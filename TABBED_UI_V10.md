# Pot of Mannah v10 — Tabbed UI

This build keeps the v9 nutrition/data features and reorganizes the web interface around actual tabs.

## Primary app tabs
- Today
- Diary
- Log Food
- Nutrition
- Planner
- Progress
- Foods

## In-page tabs
- Diary: Meals, Water, Notes, Day Tools
- Nutrition: Overview, Missing, Macros, Vitamins, Minerals, Foods to Add
- Planner: Smart Picks, Your Gaps, Planning Tools
- Progress: Overview, Calories, Consistency, Weight, Achievements
- Foods: Saved Foods, Favorites, Create Custom
- Account: Personal, Goals, Themes, Security

Tabs support URL hashes (for example `/nutrition#vitamins`) and remember the last selected tab during the browser session.
